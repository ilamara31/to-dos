# to-dos

A simple, beautiful to-do app. **Sponsored by ilan Games.**

- Today's list with voice input (mic button), confetti when you finish a task
- Postpone, edit or delete any to-do
- Plan ahead for tomorrow, next week, or any date
- Unfinished to-dos carry over as "Left from earlier"
- Works offline and can be added to the Dock (Safari → File → Add to Dock)

Your to-dos are saved in your browser on this device.

## Run locally

```sh
python3 -m http.server 8765
```

Then open http://localhost:8765
